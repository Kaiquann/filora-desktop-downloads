# Filora Desktop

Filora Desktop portfolio preview for Windows x64 by [Liew Kai Quan](https://kleft.me/).

[Download on GitHub](https://github.com/Kaiquann/filora-desktop-downloads/releases/latest) · [View the project demo](https://kleft.me/projects/filora)

## Install

Extract the entire ZIP, then open `Filora.exe` from the extracted folder. This preview is unsigned, so Windows may show a publisher warning. Check this release page for newer public previews.

The release includes a SHA-256 checksum.
